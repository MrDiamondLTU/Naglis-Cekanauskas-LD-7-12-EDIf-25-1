Paslaugos

Paslaugos, kurias galiu pasiūlyti remdamasis studijose įgytomis žiniomis.

Tinklalapių programavimas

Paprastų asmeninių ir prisistatymo svetainių kūrimas naudojant HTML, CSS ir Bootstrap.

Duomenų vizualizavimas

Matematinių funkcijų ir duomenų 2D bei 3D grafikų braižymas MATLAB aplinkoje.

Kompiuterių priežiūra

Programinės įrangos diegimas, sistemos konfigūravimas ir pagalba sprendžiant problemas.

Projekto talpinimas GitHub

Saugyklos sukūrimas, versijų valdymas ir svetainės publikavimas per GitHub Pages.
